## 🔧 How to Run

### Start the Server
```bash
cd /workspaces/Styled-portfolio-website
python3 -m http.server 8000
```

### Access the Website
1. Open your browser
2. Navigate to `http://localhost:8000`
3. Explore all pages using the navigation bar
4. Test responsive design by resizing the browser window
